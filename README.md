# ApkZY Web

Website publik ApkZY untuk GitHub + Vercel.

- `index.html` = halaman utama
- `style.css` = tampilan + 5 tema
- `app.js` = membaca `data.json`, pencarian, kategori, kartu APK
- `config.js` = konfigurasi publik
- `data.json` = data yang dipublish dari APK Admin

**Penting:** jangan masukkan GitHub Personal Access Token ke repository publik.
